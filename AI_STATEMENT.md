## 3. Human Verification & Auditing Steps

To ensure scientific integrity, code correctness, and data accuracy, all AI-suggested modifications underwent rigorous human oversight prior to execution and reporting.

Independent mathematical verifications were done at every step, particularly regarding theoretical number of microstates, and theoretical time-complexities.

Furthermore, every line of suggested code was inspected meticulously to prevent incorrect executions or conceptual errors.

AI-generated numerical routines were validated with automated pytest tests against exact integer values (`math.comb`), the identity Σ_k Ω(N,k) = 2^N, the symmetry Ω(N,k) = Ω(N,N−k) and probability normalization.

Finally, all tables and graphs were verified according to theoretical results and code generated in order to find any possible bug or inaccuracy.
